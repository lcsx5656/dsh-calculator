# dsh-calculator · DSH 计算器

> 在 DeepSeek Harness Desktop 里按 **Ctrl+Q**，随时随地弹出一个计算器。
> 不用切窗口、不用掏手机、不用污染聊天记录。

一个纯前端浮层插件：**表达式计算 / 时间单位换算 / 命名变量存储**，三页搞定。
数据全部落在浏览器 `localStorage`，重启 DSH 不丢；卸载后彻底消失，不留一条 DOM。

```
Ctrl+Q  ──►  ┌─────────────────────────────────┐
             │  计算器   [计算] 时间  存储   ✕ │
             ├─────────────────────────────────┤
             │  200+10%                        │
             │  220                   点击复制 │
             │  MC  清空记忆  MR  M+  M-       │
             │  ── 历史 ──────────────────────  │
             │  1+1                              2 │
             │  2^10                          1024 │
             └─────────────────────────────────┘
```

## 亮点

| | 能力 |
| --- | --- |
| **零侵入** | 宿主半边空实现，界面是 `document.body` 级浮层，不注册插槽、不碰官方 DOM、不写会话 |
| **不用 eval** | 手写 tokenizer → AST → 求值器，运算符优先级、右结合、隐式乘法全部自己算 |
| **智能百分比** | `200+10%` = 220，`200*15%` = 30，`7%3` = 1 —— 双语义按上下文自动判断 |
| **输入宽容** | 全角/中文符号自动纠正，`（1＋2）×3` = 9；`3k`、`2.5M`、`1w` 直接认 |
| **时间换算 8 行输出** | 秒 / 毫秒 / 分 / 时 / 天 / 周 / `01:02:03` / `1小时2分3秒` 一次算全 |
| **9 种时间写法** | `90s` `1.5h` `1:30` `1:02:03` `2h30m` `1天2小时3分4秒` … 全认 |
| **变量** | 输入 `x=5` 回车即存，之后任何算式写 `x` 自动代入 |
| **持久化** | 变量、记忆 M、60 条计算历史、20 条时间历史，退出重开还在 |
| **自带测试** | 83 项引擎自测 + 31 项冒烟测试，一条命令跑完 |

## 一、安装

**方式 A · 一键（Windows，推荐）**

1. 把整个 `dsh-calculator` 目录放到：

   ```
   %USERPROFILE%\.dsh\plugins\dsh-calculator
   ```

2. 双击 `点我一键安装.bat` —— 脚本会备份 profile、写入依赖、建立目录联接。
3. **完全退出 DSH Desktop 再重开**（关窗口不够，要退出进程）。
4. 按 `Ctrl+Q`。

**方式 B · 手动**

把 `cordis.patch.yml` 里的条目插进 profile 的层栈，然后重启：

```yaml
- insert:
    - id: dsh-calculator
      name: 'dsh-calculator'
      config:
        enabled: true
```

> 卸载：双击 `点我一键卸载.bat`，同样重启。浮层、样式、`localStorage` 键 `dsh-calculator:v1` 一并清理干净。

## 二、快捷键与交互

## 三、计算页

### 运算符

```
+   -   *   /   %   ^   !   (   )
```

| 写法 | 结果 | 说明 |
| --- | --- | --- |
| `7%3` | 1 | 取模 |
| `200*15%` | 30 | 后缀百分比 → 乘 |
| `200+10%` | 220 | 智能百分比 → 加自身 10% |
| `2^3^2` | 512 | `^` 右结合 |
| `5!` | 120 | 阶乘（>170 返回 Infinity，负数/小数报错） |
| `2(3+4)` | 14 | 隐式乘法 |
| `3sqrt(9)` | 9 | 数字贴函数 |
| `（1＋2）×3` | 9 | 全角/中文符号自动纠正 |

### 函数（39 个）

```
三角     sin cos tan asin acos atan
双曲     sinh cosh tanh asinh acosh atanh
对数     ln log log10 log2 exp
根幂     sqrt cbrt pow hypot
取整     floor ceil round trunc abs sign
数值     min max mod gcd lcm sum avg clamp atan2
角度     deg rad
其它     fact
```

### 常量与简写

- `pi` `e` `tau` `phi`
- `ans` —— 上一次按 Enter 的结果
- `mem` / `M` —— 记忆值
- 单位后缀：`3k` = 3000 · `2.5M` = 2500000 · `1G` = 1e9 · `1T` = 1e12 · `1w` = 10000

### 记忆键

`MC` 清空 · `MR` 读出 · `M+` 加当前结果 · `M-` 减当前结果

### 变量

在计算页输入 `x=5` 回车即存；之后 `x*3` = 15。存储页可查看、回填、删除。

### 错误提示（人话版）

除零、未知变量、函数缺括号、阶乘参数非法、括号不匹配…… 一共 6 类，全部给中文提示，不甩 `NaN`。

## 四、时间页

输入框认这些写法：

| 输入 | 含义 |
| --- | --- |
| `90` | 90（单位由下方芯片决定，默认秒） |
| `90s` `90秒` | 90 秒 |
| `2分钟` `2m` | 120 秒 |
| `1.5h` `90min` | 按单位换算 |
| `1:30` | 1 分 30 秒 = 90 秒 |
| `1:02:03` | 1 时 2 分 3 秒 |
| `2h30m` | 2 时 30 分 |
| `1天2小时3分4秒` | 复合中文写法 |
| `-5m` | 负数 |

单位芯片：**自动 / 秒 / 分 / 小时 / 天** —— 选「分」时纯数字 `90` 就当 90 分钟。

输出固定 8 行，点任意一行即复制：

```
纯秒     3723 s
纯毫秒   3723000 ms
纯分钟   62.05 min
纯小时   1.03416666667 h
纯天     0.0430902777778 d
纯周     0.00615575396825 w
时分秒   01:02:03
中文     1小时2分3秒
```

最近 20 条换算历史落在存储页，点一条跳回时间页重算。

## 五、存储页

| 区块 | 内容 |
| --- | --- |
| **变量** | 全部命名变量，点名字回填、点 `×` 删除、`全清` 一次清空 |
| **记忆 M** | M+/M- 累积值，独立于变量，`归零` 重置 |
| **时间换算历史** | 最近 20 条，点击跳转并重算 |
| **计算历史** | 最近 60 条，随输入自动持久化 |

持久化键：`localStorage["dsh-calculator:v1"]`。

## 六、目录结构

```
dsh-calculator/
├── package.json         插件清单（dsh.client.platform = web）
├── cordis.patch.yml     把插件插入 profile 层栈
├── index.js             宿主半边：刻意空实现，只作 cordis 挂载点
├── client.js            全部实现：tokenizer + 求值器 + 时间换算 + 浮层 DOM
├── test/
│   ├── run.mjs          83 项引擎自测
│   └── smoke.mjs        31 项冒烟测试（DOM 构建、状态机、格式化）
├── scripts/
│   ├── install.ps1      备份 profile → 写依赖 → 建目录联接
│   └── uninstall.ps1    反向清理
├── 点我一键安装.bat
└── 点我一键卸载.bat
```

**设计纪律**（写死在代码注释里）：

- `index.js` 的 `apply` 绝不抛错、绝不注册服务、绝不改配置 —— 最坏情况只是浮层不出现，不能连累宿主启动。
- `client.js` 全程 `try/catch`，异常只打一条 `console.warn`，绝不影响输入区。
- 不写会话消息、不劫持官方快捷键以外的按键、不申请任何网络权限。
